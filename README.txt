RAG-Based Multi-PDF Chatbot

This project implements a question-answering chatbot using Retrieval-Augmented Generation (RAG) over multiple PDF documents.

Features:

Multi-PDF Processing,
Text Chunking,
Embeddings with Sentence Transformers,
FAISS ,
Vector Search,
LLM-based Answer Generation,
Streamlit Interface



Tech Stack:

Python,
LangChain,
Hugging Face Transformers,
Sentence Transformers,
FAISS,
Streamlit
